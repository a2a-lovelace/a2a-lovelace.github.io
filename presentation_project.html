📏 Шкала баллов (Раздел 22.2.1)

0Функция отсутствует в имеющейся конфигурации
2Реализована частично, нужна серьезная доработка кода

10Реализована полностью, удовлетворяет всем требованиям

Допускаются нечетные оценки для пограничных случаев

⚖️ Весовые коэффициенты (Раздел 22.2.3)

1Функция имеет низкую важность
2Функция важна в информационной системе
3Функция критически важна

📦 Рассматриваемые Self-Hosted решения

WordPress + WooCommerce

+ плагины лицензий (Licenzo)

  • Популярная CMS (43% сайтов)
  • Бесплатная основа
  • Платные плагины лицензий ($49/год)
  • Сложная настройка (Apache/PHP/MySQL)
  • Избыточный функционал

⚠️ Требует LAMP-стек

OpenCart / LiteCart

специализированные CMS

  • Заточены под интернет-магазины
  • Open-source
  • Скудная экосистема плагинов
  • Высокий порог входа
  • Устаревший интерфейс

❌ Нет плагинов для лицензий

🏆 Python + Streamlit

самописное решение (MVP)

  • Полный контроль над кодом
  • 100% бесплатно
  • Развертывание: 1 команда
  • Гибкая кастомизация
  • Современный стек (Python 3.x)

✅ Оптимально для MVP
